1它是什么

一句话：把「她的事」记在一个只有你能看的地方，需要的时候替你记住。

这是给一个人用的私人记事本 —— 不是社交产品、不是情侣共享 App。 记的是关于「她」的事：喜欢什么、脾气怎样、在意什么、讨厌什么。 数据全部存在你手机里，不上传任何服务器，也没有账号体系。

它和普通备忘录的区别在于三件事：① 记的时候有四个固定分类帮忙归类； ② 每条记录都能挂提醒（到点响、或到你常去的地方响）； ③ 改过的内容会留下历史版本，改错了能翻回去看。

📝 记

四分类 + 标签 + 最多 9 张配图，随手记下，不用想放哪

🔔 提醒

定时（每周三 20:00）和场景（到公司就提醒），最多提前一天

🕐 留痕

每次改动自动存一版，可以左右对比，也能恢复旧版

3技术底座（你不必懂，但改功能时会用到）

这一节是给「提需求」用的：知道边界在哪，就不会提做不了的事。

技术选型

  • SwiftUI + SwiftData，最低 iOS 17
  • 零第三方依赖（不装任何外部库）
  • 三个 target：主 App + 通知扩展 + 分享扩展
  • 仓库：github.com/haohao234/She

数据都在哪

  • 记录、档案、提醒、情绪、历史版本 → 手机本地数据库
  • 照片 → 手机本地文件（按内容 hash 命名）
  • 不上传、不同步、没有服务器
  • 换手机 / 重装 = 数据不跟随（导出 JSON 可以带走）
⚠
三条硬边界（不是没做，是做不了）：
① 读不到你的聊天记录 —— iOS 沙盒不允许，任何 App 都不行。
② 场景提醒最多 20 个 —— iOS 对地理围栏的硬上限，超了会静默失效。
③ 免费账号签的包只活 7 天 —— 这是 Apple 的限制，靠自动续签绕过（见第 5 节）。

4后续改功能：完整流程

你只需要做两件事：说清要什么、装新包。中间的编译我来跑。

▸
核心机制：你不需要 Mac。 代码推上 GitHub 后，云端会自动用 macOS 编译；编译结果直接回在网页上。 所以「改功能 → 拿到新包」这条链路，你的操作只有双击一个脚本和下载安装。

改一个功能的完整过程

  1. 跟我说要改什么（用大白话就行）

    比如「加一个『纪念日倒计时』」「提醒想支持农历」「导出加个 Word」。 不用管技术细节，说清「谁在什么时候会想用它、现在哪里别扭」比说实现方式有用得多。

    如果我判断这事和设计稿冲突、或者 iOS 做不到，我会直说并给替代方案 —— 不会闷头做完才告诉你。

  2. 我改代码 + 改设计稿 + 更新文档

    这个项目一直是三件交付物同步走：设计稿、可交互原型、iOS 代码。 加一个屏的话三边都要动，我会一起做完 —— 只改代码会造成「文档说的和 App 不一样」， 那比没文档更糟。

  3. 本地先自查，再推上去

    推之前我会跑 7 份校验脚本（近 200 项检查）—— 抓参数顺序、抓漏加的模型登记、 抓文档里悬空的链接、抓扩展数量对不对。能静态发现的问题绝不留给云端编译器。

  4. 你双击 push-to-github.bat，连按两次回车

    脚本在 她的信息本-iOS 文件夹里。它自己找 git、自己重试网络。 看到「成功」就行；失败就把屏幕上的字发我。

    也可以我这边直接推 —— 但网上时通时断，所以脚本里加了自动重试，你用脚本更稳。

  5. 等 1～5 分钟，看 Actions 是绿还是红

    绿 = 编译过了，可以下包。红 = 把报错发我（我能直接读到是哪一步、错在哪一行， 不用你翻日志）。

  6. 下新包、拖进 Sideloadly 重装

    网页上点最上面（最新）那次运行 → 下 HerInfo-ipa → 解开 zip → 拖里面的 .ipa（约 1.15 MB）。

    拖之前瞄一眼 Sideloadly 第一行 Using IPA file: —— 确认拖的是刚下的新包（这一个动作能省掉一整轮排查）。

i
重装会不会丢数据？ 用同一个 Apple ID 覆盖安装，数据保留； 但如果 Sideloadly 的「自动 Bundle ID」重新生成了后缀，系统会当成另一个 App，数据就不跟过来。 所以建议关掉 Use automatic bundle ID，手动固定一个 id —— 之后就一直是覆盖安装。

5⚠️ 每 7 天要留意的一件事

这是目前唯一的「定期维护动作」，现在就该设好。

免费 Apple ID 签出来的包只有 7 天有效期。到期后 App 会突然打不开 —— 图标还在，点一下就闪退，看起来像「App 坏了」。

但它其实没坏，只是签名过期。Sideloadly 能自动保住它：

  • 打开 Sideloadly，勾上 auto-refresh（自动刷新）
  • 之后只要电脑和手机在同一个 Wi-Fi（或者插着线），它会在到期前自动重新签好
⚠
万一真的打不开了：别卸载重装。 卸载会把记过的内容一起清掉 —— 而数据是存在 App 沙盒里的，删了 App 就没了。 打不开 ≠ 数据丢了，重新签一次就好（这也是为什么要提前开自动续签）。
